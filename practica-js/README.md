## 🎯 Estructura del Curso

### NIVEL 1️⃣: FUNDAMENTOS BÁSICOS (1 semana)
**Archivo:** `01-fundamentos.js`

**Temas:**
- Variables (const, let, var)
- Tipos de datos primitivos
- Strings y operaciones
- Números y matemáticas
- Booleanos y operadores lógicos
- Comparaciones
- Conversión de tipos
- Operador ternario
- Scope

**Objetivos:**
- Entender cómo funciona JavaScript
- Manejar variables y tipos de datos
- Realizar operaciones básicas
- Comprender el concepto de scope

---

### NIVEL 2️⃣: CONDICIONALES Y BUCLES (1 semana)
**Archivo:** `02-condicionales-bucles.js`

**Temas:**
- if/else/else if
- switch
- Bucles (for, while, do-while)
- break y continue
- Arrays
- for...of
- for...in
- forEach, map, filter, find, reduce
- slice y splice

**Objetivos:**
- Controlar el flujo del programa
- Trabajar con colecciones de datos
- Manipular arrays de forma eficiente
- Usar métodos funcionales

---

### NIVEL 3️⃣: FUNCIONES (1 semana)
**Archivo:** `03-funciones.js`

**Temas:**
- Funciones básicas
- Parámetros y return
- Parámetros por defecto
- Funciones anónimas
- Arrow functions (=>)
- Spread operator
- Rest parameters
- Destructuring
- Closures
- Recursión

**Objetivos:**
- Escribir código reutilizable
- Entender scope y closures
- Usar arrow functions correctamente
- Dominar técnicas funcionales

---

### NIVEL 4️⃣: OBJETOS (1 semana)
**Archivo:** `04-objetos.js`

**Temas:**
- Objetos literales
- Métodos de objetos
- Objetos anidados
- Destructuring de objetos
- Spread operator con objetos
- this binding
- Constructores
- Clases (ES6)
- Herencia
- Getters y Setters
- Métodos de Object

**Objetivos:**
- Trabajar con objetos complejos
- Usar clases modernas
- Entender herencia en JavaScript
- Dominar this

---

### NIVEL 5️⃣: ASINCRONÍA (1-2 semanas)
**Archivo:** `05-asinconia.js`

**Temas:**
- Callbacks
- Promesas
- Encadenar promesas
- Async/Await
- Try/Catch
- Fetch API (GET y POST)
- Promise.all
- Promise.race
- Manejo de errores

**Objetivos:**
- Trabajar con datos asincronos
- Entender flujos no-bloqueantes
- Usar Fetch API para obtener datos
- Manejar errores correctamente

---

### NIVEL 6️⃣: DOM (1-2 semanas)
**Archivos:** `06-dom.js` + `ejemplo-dom.html`

**Temas:**
- Seleccionar elementos
- Manipular contenido
- Cambiar atributos
- Estilos CSS
- Crear elementos
- Eliminar elementos
- Event listeners
- Formularios
- Event delegation
- Timers

**Objetivos:**
- Interactuar con el HTML desde JavaScript
- Crear experiencias interactivas
- Manejar eventos del usuario
- Validar formularios

---

### NIVEL 7️⃣: CONCEPTOS AVANZADOS (2 semanas)
**Archivo:** `07-conceptos-avanzados.js`

**Temas:**
- Prototipos
- Cadena prototípica
- This binding (call, apply, bind)
- Map y Set
- Destructuring avanzado
- Template tags
- Proxy
- Symbol
- Generators
- Iterables
- Regular expressions
- Debounce y Throttle

**Objetivos:**
- Entender programación avanzada
- Trabajar con estructuras de datos especiales
- Crear patrones complejos

---

### NIVEL 8️⃣: RESUMEN Y ROADMAP (Referencia)

## ❓ Preguntas Frecuentes

**P: ¿Puedo saltarme algunos niveles?**
R: No recomendado. Cada nivel construye sobre el anterior.

**P: ¿Cuánto tiempo debo practicar diariamente?**
R: Al menos 2-3 horas consistentes. Mejor poco y consistente que mucho esporádico.

**P: ¿Necesito memorizar todo?**
R: No. Es mejor entender y poder buscar referencias. Con la práctica vendrá la memorización natural.

**P: ¿Debo aprender todas las APIs?**
R: No. Aprende los conceptos principales, luego descubrirás APIs según necesites.

**P: ¿Qué hago cuando algo no funciona?**
R: 1) Lee el error 2) Busca en Google 3) Pregunta en comunidades 4) Tómate un descanso
